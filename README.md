This repository contains the code for the published paper

**“Tailoring Bayesian Additive Regression Trees (BART) for environmental mixture studies”**

by Kaizong Ye, Zhen Chen, and Shanshan Zhao.

## Contents

- **`ModSoftBART/`**\
  R package implementing the proposed ModSoftBART method.

- **`empirical/`**\
  Empirical analysis on NHANES data:

  - `NHANES data analysis.R`

- **`simulation/`**\
  Simulation examples:

  - `simulation_example_binary.R`
  - `simulation_example_continuous.R`

## Requirements

Please install the required packages listed in the scripts before running the examples.
